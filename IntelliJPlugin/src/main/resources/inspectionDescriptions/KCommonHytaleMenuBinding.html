Reports calls on a Hytale MenuBuilder or MenuRow that would throw when the menu is built: a key its YAML doesn't have (bindTo, show, text, set, visible, disabled, specialPlaceholders, addRow), text() on an element type without text, set() of a property the element type doesn't have, and addRow into an element that can't hold rows or from a missing template.

The builder is traced back to the getOrLoad("path", MenuBuilder.class) call that loaded it.
